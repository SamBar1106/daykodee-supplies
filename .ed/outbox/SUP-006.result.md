# SUP-006 result

Implemented formatted product descriptions using DOMPurify. Catalog cards and the product page share a renderer that only inserts sanitized HTML. Allowed tags: p, br, strong, em, b, i, ul, ol, li, a. Only href attributes are allowed; DOMPurify rejects unsafe URLs. Scripts, event handlers, styles, and other elements are removed.

HTML descriptions remain intact instead of being split at source newlines. Card previews are limited to three lines. Existing plain-text subtitle/body splitting and newlines are preserved.
