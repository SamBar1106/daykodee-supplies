## Background

Today `src/lib/catalog.js` `categoryOf` guesses one of four fixed tabs from words in the product name/description, and `src/lib/config.js` `CATEGORIES` is `["All", "Classroom", "Rest time", "Sanitation", "Outdoor"]`. After Web Dev added 8 real Wix supply categories, only Classroom and Outdoor show on supplies.daykodee.com.

The franchise-catalog API (SUP-007, separate repo) will return each product with:

```json
"categories": [
  { "id": "41374cc1-390d-4fac-be9d-753a730ec633", "name": "Classroom & Art Supplies" }
]
```

These are subcategories of hidden parent "Franchise (test)". A product with no subcategory has `"categories": []`.

## Change

Build catalog tabs from those API categories instead of the keyword guess.

- Tabs: `"All"`, then the unique category **names** present on the loaded items, in a stable order (e.g. first-seen in catalog order, or alphabetical — pick one and test it).
- A product appears in `"All"` and in each of its category-name tabs.
- If a product has no usable category (missing, empty, or nameless `categories`), put it in a fallback tab named `"Other"`. `"Other"` appears only when at least one such product exists.
- Keep `categoryOf` / `categoriesFor` as the helpers used by `CatalogPage` (and anywhere else that filters by group). Change their meaning: `categoryOf` is no longer a keyword guess. Prefer a small helper that returns the item's category names (and `"Other"` when none).
- Remove dependence on the fixed four-name `CATEGORIES` list for tab building. You may leave a deprecated export only if tests need a careful migration; otherwise delete or stop using it.
- Update `src/lib/demoCatalog.js` so `?demo=1` items have `categories: [{ id, name }, ...]` using the real Wix subcategory names (and invented demo ids is fine). Cover more than one category so demo tabs are useful. Demo items without categories should fall into `"Other"` if you leave any that way; prefer assigning them.
- Do not change auth, checkout, image handling, CNAME, GitHub Pages, Wix, DNS, or the franchise API server.
- Do not edit or rebase `ed/SUP-006`. This branch is from `origin/main` only. Do not take SUP-006 description/DOMPurify work onto this branch.

## Tests and build

`npm test` is `node --test src/lib/*.test.js`. Update and add coverage:

- An item with `categories: [{ id, name: "Kitchen & Food Service" }]` is grouped under `"Kitchen & Food Service"`, not a keyword guess from its name.
