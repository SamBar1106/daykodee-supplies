## Bug

After a passing franchisee sign-in test, Web Dev reported that product descriptions show raw HTML tags. Example:

    <p>TEST ITEM - not for sale</p>

Wix product descriptions can contain HTML. The portal currently treats description as plain text (subtitleOf / bodyOf, then React text nodes on catalog cards and the product page), so the tags are visible.

## Fix

Render descriptions as formatted text, sanitized with DOMPurify (preferred), or strip them to plain text.

- Prefer DOMPurify and render safe formatted HTML (typography only: p, br, strong, em, b, i, ul, ol, li, and a with safe hrefs).
- Never unsanitized dangerouslySetInnerHTML.
- Cover every place a product description or a description-derived subtitle or body is shown, at least catalog cards and the product page.
- Keep plain-text descriptions with newlines working.
